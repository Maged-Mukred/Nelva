# Nelva Corporate Website

Official website of Nelva, a Finland-based international market development
company supporting technology manufacturers.

## Positioning

Nelva helps technology manufacturers understand, enter, and develop
international markets through structured market intelligence, qualification,
relationship development, manufacturer representation, and technical and
commercial coordination.

Payment technology is Nelva's strongest current specialist area.

## Website

The website includes:

- Home
- Company
- Capabilities
- Industries
- Contact

The design direction is Nordic Structuralism: precise typography, a disciplined
grid, restrained colour, and clear editorial hierarchy.

## Development

```bash
pnpm install
pnpm run dev
pnpm run build
pnpm test
```

Built with React, TypeScript, vinext, and the OpenAI Sites deployment runtime.
